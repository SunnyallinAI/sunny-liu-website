# Public Assets

This directory contains static assets for your website.

## Required Images

1. **profile.jpg** - Your profile photo (recommended: 400x400px)
2. **og-image.jpg** - Open Graph image (recommended: 1200x630px)
3. **favicon.ico** - Site favicon

## Optional Images

- **blog/** - Blog post images
- **projects/** - Project screenshots
- **logos/** - Company logos

## Image Optimization

All images should be:
- Optimized for web (use tools like TinyPNG or Squoosh)
- Properly sized for their display context
- Saved in appropriate formats (JPEG for photos, PNG for graphics)
